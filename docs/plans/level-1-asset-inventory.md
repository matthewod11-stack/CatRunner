## Locked Phase 0 Decisions

1. Level 1 ships with a curated animated runner hero sheet as the gameplay baseline.
2. Live cat generation is optional and off the gameplay critical path.
3. World art is generated or authored outside the runtime, cleaned, committed, and loaded by deterministic Phaser keys.
4. Beach is the proving ground for the repeatable level-art pipeline; do not generalize beyond Beach until the Beach pass is playable and verified.
5. `RunnerScene` should move from scattered hard-coded asset keys toward a Beach asset manifest or key registry before final art tuning.

## Critical Path

- Beach art brief and prompt pack
- final Beach environment layers
- final obstacle and collectible pack
- final background entity pack
- Sand Monster state pack
- default Beach runner hero sheet
- Beach asset manifest / key registry
- `RunnerScene` loading, animation, scale, baseline, and hitbox tuning
- focused Beach manual playtest
- `npm run test:run`, `npm run test:smoke`, `npx tsc --noEmit`, and `npm run build`

## Deferred

- live closet generation changes
- dynamic per-user animated gameplay cats
- runtime world-art generation
- full-campaign art polish
- multi-level asset abstractions beyond reusable templates proven by Beach

## Target Directory Shape

```text
assets/
  sprites/
    beach/
      environment/
      obstacles/
      collectibles/
      entities/
      boss/
```

The current flat `assets/sprites/*.png` files can remain while Phase 1 art is produced, but final Level 1 integration should read from the level-local Beach layout or a manifest that points there.

## First Runtime Integration Targets

1. Create a Beach asset manifest or key registry for deterministic Phaser load keys. `DONE: scenes/runner/beachAssets.ts`.
2. Move final Beach art into `assets/sprites/beach/` or manifest-addressed equivalents. `DONE: Phase 1 SVG pack`.
3. Replace `RunnerScene` placeholder texture reuse for `SAND_PROJECTILE`, `SPEED`, `MAGNET`, and `SUPER_SIZE`. `DONE`.
4. Wire the default runner hero sheet and animation state handling in `RunnerScene`. `DONE: Phase 2`.
5. Tune scale, origin, baseline, and collision boxes against the final art. `PHASE 4`.
